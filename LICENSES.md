# Uso e licenças

DubStudio é destinado a edição de mídia com autorização dos titulares. O projeto não incorpora soluções de contorno de DRM. Bibliotecas externas mantêm licenças próprias: Python, Qt/PySide6, NumPy, SoundFile, sounddevice, imageio-ffmpeg, FFmpeg, faster-whisper, CTranslate2, Requests e PyAV. Consulte os avisos de licença de cada distribuição.
